#### 🎫 Ticketify
*Enterprise Ticketing & Field-Service Portal*
- Built with **Blazor Interactive Server (.NET 10)**, Razor components, and Radzen Blazor UI.
- Implemented claims-based authentication, role-based access control (RBAC), filterable data grids, and responsive modal workflows.

#### 📦 Export Packing Station & Live Andon
*Manufacturing Digitization & Dispatch Platform*
- Digitized SO Entry, Box Allocation, Customs Invoicing, and Dispatch lifecycles using **Blazor Server, ASP.NET Core, MudBlazor, and SQL Server**.
- Developed live shop-floor **Andon visual management boards** and RBAC modules to cut manual reporting and track operational bottlenecks.

#### 🦴 Bone Shape Sculptor
*Medical 3D Reconstruction Platform*
- Converts 2D CT scans into accurate 3D bone models using **Marching Cubes** and **VTK**, cutting mesh generation time by 30%.
- Achieved medical-grade bone segmentation (200–3000 HU) with sustained 40–45 FPS WebGL rendering on 512×512×400 CT datasets.
- **Tech**: React, Three.js, Python Flask, VTK.

#### 🩺 Doctor-Chat
*Hybrid AI/Live Specialist Healthcare Platform*
- Real-time bi-directional messaging platform handling 200+ concurrent connections with sub-20ms latency and session load-balancing.
- Integrated Groq API conversational AI with context-aware chat memory for continuous medical triage.
- **Tech**: Node.js, Express, React, Socket.IO, Groq AI, MongoDB.
